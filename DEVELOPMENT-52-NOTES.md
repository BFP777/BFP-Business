# Development 52 — Supplier Purchase Intelligence

- Added a supplier-wise purchase summary with bill count, recorded purchase total, recorded outstanding, GSTIN and latest purchase timestamp.
- Added a supplier/item-wise comparison of the latest and immediately previous purchase rate, using only Item Master-linked purchase lines.
- The report is read-only and informational: it does not create or modify purchase, stock, payment, cash or bank entries.
- The screen is reachable from Menu → Inventory Intelligence → Supplier Purchase Insights.
- Kept the database schema at version 8; this release adds DAO projections and UI only, so no migration is required.
- Updated app version to 5.7.0 (versionCode 507).
- Verification executes the exact supplier summary and rate-comparison SQL against SQLite fixtures.

## User-friendly alert policy

- No pop-up warnings are generated by this report.
- Rate differences are shown as quiet information cards; there are no automatic purchase suggestions or postings.
- Outstanding values are presented from the existing invoice `paidPaise` records and should be reconciled with the party ledger if payments have been edited elsewhere.
