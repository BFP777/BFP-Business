# Development 71 – Voice Item Entry Default Language

- Removed the language-selection dialog from every Voice Item Name button press.
- Voice recognition now starts directly in English (`en-IN`) by default.
- The selected voice language is remembered in app preferences.
- Hindi remains available as an optional persistent setting under Menu → Utilities → Voice Input Language; it is not prompted on each item entry.
- Recognized text continues to populate the editable item-name field; it is not auto-saved.
